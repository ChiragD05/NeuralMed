# AI-Powered Medical Decision Support Assistant

A multi-feature AI healthcare decision-support system built with Streamlit, Supabase, NLP, CNNs, Transformers, RAG, OCR, and voice AI.

## Features
- Symptom analysis
- Medical image classification
- Report summarization
- Prescription OCR
- Disease risk prediction
- Voice assistant
- AI doctor chatbot

## Tech Stack
- Streamlit
- Supabase
- Python
- Transformers
- PyTorch
- EasyOCR
- FAISS
- SpeechRecognition / gTTS

## Safety
This project is for educational decision support only and does not provide medical diagnosis.
